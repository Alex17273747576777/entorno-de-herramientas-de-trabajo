## 1. Novato absoluto (nunca has programado)

Objetivo: perder el miedo, entender qué es un programa, escribir tus primeras líneas.

- ⭐ **freeCodeCamp** — <https://www.freecodecamp.org/> — interactivo, con proyectos y certificados gratis. Tiene [versión en español](https://www.freecodecamp.org/espanol/). **La puerta de entrada nº 1 que recomienda FMHY.**
- ⭐ **The Odin Project** — <https://www.theodinproject.com/> — ruta completa de desarrollo web, gratis, basada en proyectos reales (te hace instalar tu propio entorno).
- **CS50x (Harvard)** ⭐ — <https://cs50.harvard.edu/x/> — la mejor intro a "cómo piensan los ordenadores", gratis y de clase mundial.
- **Scratch** — <https://scratch.mit.edu/> — programación visual por bloques; ideal si quieres entender la lógica sin sintaxis (FMHY lo lista para principiantes).
- **FutureCoder** — <https://futurecoder.io/> — Python interactivo y muy guiado, con depurador integrado.
- **Learn Python** — <https://www.learnpython.org/> — tutorial interactivo corto de Python.
- **Karel the Robot / Code.org** — lógica básica en entornos de enseñanza (los cita FMHY).

**Juegos para practicar lógica:** CodinGame, Checki0, Codepip, Flexbox Froggy, Grid Garden, CSS Diner (todos en la lista de FMHY).

## 2. Fundamentos con un primer lenguaje de verdad

Elige **un** lenguaje y hazlo a fondo. FMHY tiene una subsección por lenguaje; los más recomendados para empezar:

**Python** (el más citado para arrancar)
- ⭐ **Automate the Boring Stuff with Python** — <https://automatetheboringstuff.com/> — libro gratis, práctico desde el día 1.
- **30 Days of Python** ⭐ — <https://github.com/Asabeneh/30-Days-Of-Python> — reto de 30 días, muy completo.
- **A Byte of Python** — <https://python.swaroopch.com/>
- **Hitchhiker's Guide to Python** — <https://docs.python-guide.org/>
- **CS50 Python** — <https://cs50.harvard.edu/python/>

**JavaScript / Web** (si te interesa hacer páginas y apps)
- ⭐ **JavaScript.info** — <https://javascript.info/> — el tutorial moderno de JS más completo y gratuito.
- **MDN Web Docs** 🌐 — <https://developer.mozilla.org/> — la biblia de HTML/CSS/JS.
- **30 Days of JavaScript** — <https://github.com/Asabeneh/30-Days-Of-JavaScript>
- **Eloquent JavaScript** — <https://eloquentjavascript.net/> — libro clásico (gratis online).
- **You Don't Know JS (Yet)** — <https://github.com/getify/You-Dont-Know-JS> — para entender JS en profundidad.
- ⭐ **Learn to Code HTML & CSS** — <https://learn.shayhowe.com/html-css/>
- **Web Dev for Beginners (Microsoft)** — <https://github.com/microsoft/Web-Dev-For-Beginners>
- **Codeguage** — <https://www.codeguage.com/> — cursos de web muy bien explicados.

**Otros lenguajes** (cuando ya tengas base):
- Go — <https://go.dev/tour/> · Rust — <https://doc.rust-lang.org/book/> y <https://github.com/ctjhoa/rust-learning> · Java/Kotlin — learncs.online · C/C++ — Learn C++, C++ Core Guidelines.

## 3. Intermedio (ya sabes programar; toca la base real)

Aquí pasas de "escribir código" a "ser ingeniero": estructuras de datos, algoritmos, full stack.

- ⭐ **Full Stack Open** (Univ. de Helsinki) — <https://fullstackopen.com/en/> — curso moderno de React/Node/GraphQL/TypeScript, gratis y con créditos. **De lo mejor para web serio.**
- **Hello Algo** — <https://www.hello-algo.com/> — estructuras de datos y algoritmos con animaciones, libro abierto.
- **VisuAlgo** — <https://visualgo.net/en> — visualiza algoritmos paso a paso.
- **The Algorithms** — <https://the-algorithms.com/> — implementaciones de algoritmos en muchos lenguajes.
- **Exercism** — <https://exercism.org/> — ejercicios con mentores humanos gratis.
- **Backendlore / Design Patterns for Humans** — patrones de diseño y backend (en la lista de FMHY).
- **Refactoring Guru** — <https://refactoring.guru/> — patrones de diseño y refactorización, muy visual.

## 4. Avanzado (informática de verdad + ingeniería inversa de sistemas)

El salto de "programador" a "informático". FMHY lo cubre con estas joyas:

- ⭐ **Build Your Own X** — <https://github.com/codecrafters-io/build-your-own-x> — construye tu propio Git, base de datos, navegador, sistema operativo, blockchain… **aprender haciendo a nivel experto.**
- **Project Based Learning** — <https://github.com/practical-tutorials/project-based-learning> — tutoriales donde construyes apps reales por lenguaje.
- **Crafting Interpreters** — <https://craftinginterpreters.com/> — escribe tu propio lenguaje de programación, paso a paso. Libro abierto, una obra maestra.
- **Nand2Tetris** — <https://www.nand2tetris.org/> — de un circuito NAND hasta un ordenador y un juego que funciona. La mejor manera de entender qué es un ordenador por dentro.
- **system-design-primer** ⭐ — <https://github.com/donnemartin/system-design-primer> — diseño de sistemas a gran escala (lo que preguntan en entrevistas senior).
- **Designing Data-Intensive Applications** — <https://dataintensive.net/> — el libro de referencia sobre sistemas de datos (de pago, pero es la biblia del nivel experto).
- **OSSU / TeachYourselfCS** (los meta-índices de arriba) — para cubrir arquitectura, SO, redes, compiladores, matemática discreta.

## Ruta sugerida si no sabes por dónde tirar

1. **Semana 1-2:** mira [roadmap.sh](https://roadmap.sh/) y decide *web* o *ciencia de datos* o *sistemas*.
2. **Mes 1-3:** [freeCodeCamp](https://www.freecodecamp.org/) o [CS50x](https://cs50.harvard.edu/x/) → aprende a programar de verdad.
3. **Mes 3-9:** [The Odin Project](https://www.theodinproject.com/) o [Full Stack Open](https://fullstackopen.com/en/) → construye proyectos.
4. **Mes 9-18:** [Hello Algo](https://www.hello-algo.com/) + [LeetCode](https://leetcode.com/) → estructuras de datos y algoritmos.
5. **Mes 18+:** [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x) + [system-design-primer](https://github.com/donnemartin/system-design-primer) + [Professional Programming](https://github.com/charlax/professional-programming) → nivel experto/senior.

Regla de oro de FMHY y de cualquiera que aprendió: **no veas cursos en bucle; construye cosas.** Cada etapa termina con un proyecto tuyo, no con un certificado.
